Остров Принцессы Ирины

локацияОстров на западе Кёнигпона

Правитель: не указан

Остров-район на западе столицы. Через него по проспекту клан Дан Балана везёт на рикше гробы и двух связанных «даров» для пробуждения Бьянки. Отсюда открываются два пути: через Вирджинвальдские ворота или по воде через Рыбачьи острова. Других сведений нет.
