Капучин

История персонажа в порядке времени Понии

год 0

Беглый бес Капучино присоединяется к отряду Пахома, который крадёт для демонов Властона гигантский адский кристалл — но на деле хочет его использовать для своих целей. Капучино насаживает рабочих на трезубец, забирая их души себе на силу, играет на баяне, оглушая вражескую стражу звуковым уроном, забирает душу гнома Виктора по контракту и получает над ним власть, а в финале добивает фаерболом ожившее сшитое чудовище-повара Юджина, охранявшее похищаемый кристалл.
